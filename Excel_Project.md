# 📊 Product Sales & Revenue Dashboard (Excel)

## 📌 Project Overview
This project focuses on analyzing raw sales data to uncover revenue trends and product performance. Using advanced Excel techniques, the data was cleaned, transformed, and modeled into an interactive executive dashboard.

## 🛠️ Tools & Skills Used
* **Advanced Excel:** Pivot Tables, Pivot Charts, Power Query.
* **Automation:** AI-assisted formula generation and automated macro structures for monthly updates.
* **Design:** Interactive Slicers and Timelines for seamless filtering.

## 🔑 Key Insights & Features
* **Top Performers:** Identified top-performing product categories driving 80% of the revenue.
* **Dynamic Filters:** Added interactive filters for deep-diving into specific categories and regions.
* **Trend Analysis:** Automated monthly sales tracking to identify seasonal spikes.

## 📁 Repository Structure
* `/Data`: Raw and cleaned sales datasets.
* `/Notebooks_or_Scripts`: Automation workflows.
* `/Output`: Final `.xlsx` dashboard file.
