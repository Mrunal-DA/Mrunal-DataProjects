# 📱 Smartphone Retail Performance Tracker (Power BI)

## 📌 Project Overview
A dynamic, end-to-end Power BI business intelligence solution designed to monitor retail KPIs, regional demand, and category performance for mobile devices.

## 🛠️ Tools & Skills Used
* **Power BI Desktop:** Data Modeling, Star Schema, Report Design.
* **DAX (Data Analysis Expressions):** Created custom measures for time-intelligence sales analysis.
* **Data Cleaning:** Power Query Editor (handling missing values, data type formatting).

## 🔑 Key Insights & Features
* **KPI Matrix:** Live tracking of total revenue, total units sold, and profit margins.
* **Regional Dynamics:** Geospatial mapping of sales to pinpoint high and low-performing territories.
* **Category Breakdown:** Granular analysis of premium vs. budget smartphone segments.

## 📁 Repository Structure
* `/Data`: Smartphone sales source data files.
* `/Reports`: Main `.pbix` Power BI file and dashboard screenshots.
