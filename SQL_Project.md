# 📚 Online Book Store Database Analysis (SQL)

## 📌 Project Overview
This project involves building a relational database schema for an online bookstore from scratch. Using SQL, I simulated customer orders, managed inventory levels, and extracted critical business insights.

## 🛠️ Tools & Skills Used
* **SQL Dialect:** MySQL / PostgreSQL.
* **Database Design:** Primary Keys, Foreign Keys, Entity-Relationship management.
* **Advanced Querying:** Joins, Aggregate Functions, Group By, Subqueries.

## 🔑 Key Insights & Features
* **Top Sellers:** Written queries to instantaneously retrieve the highest-selling book titles based on volume.
* **Customer Trends:** Identified purchasing behaviors, average order value, and loyal user segments.
* **Stock Alert:** Automated calculation queries to pinpoint items that need immediate inventory restocking.

## 📁 Repository Structure
* `/Scripts`: Clean `.sql` script files containing schema creation and reporting queries.
* `/Data`: Sample insert statements and mock tables.
